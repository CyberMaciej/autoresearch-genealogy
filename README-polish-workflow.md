# Polish Workflow

## Order of operations
1. Start with `test-cases/pilot-case.md`
2. Normalize the surname and all name variants
3. Resolve locality candidates
4. Use `prompts/01-tree-expansion-pl.md`
5. Record evidence in `vault-template/templates/person.md`
6. Audit weak claims with the source auditor

## Rules
- Locality matters more than surname
- User trees are leads, not evidence
- Preserve spelling variants
- Log negative searches
